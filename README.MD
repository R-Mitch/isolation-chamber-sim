# Isolation Chamber Sim & Metabolic Firewall Framework

## Overview
This repository contains the official simulation suite and technical implementation for **"The Metabolic Firewall: Why Consciousness is a Compression Artifact, Not a Window to Reality."** 

The project formalizes cognitive architecture through Shannon entropy ($H(X)$) and thermodynamic cost functions, proving mathematically and empirically that lossy compression (the "ego loop") is a mandatory evolutionary barrier against computational insolvency.

## Repository Structure
* `simulation.py` — Discrete-time simulation proving the phase transition between unconstrained high-bandwidth agents and compressed metabolic firewall architectures.
* `mge_proxy.py` — The Metabolic Gating Engine (MGE) prototype implementing dynamic entropy-based token pruning for energy-constrained LLM and edge inference.
* `manuscript.tex` — Complete LaTeX source for the academic paper.

## Quick Start (Colab / Python)
Run `simulation.py` in Google Colab to replicate the phase-transition stress test showing how unconstrained agents breach energy limits instantly while firewall-constrained agents maintain operational longevity.
